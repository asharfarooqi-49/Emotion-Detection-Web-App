# Emotion Detector Web Application

Project Description:
This project is a web application developed to analyze and identify human emotions through text or media input. It integrates Embeddable Watson AI libraries to leverage advanced natural language processing and machine learning models for high-accuracy sentiment and emotion detection.

Key Features:

AI Integration: Utilizes IBM Watson's AI capabilities for real-time emotion analysis.

Web Interface: A user-friendly web application designed for seamless interaction and data visualization.

Emotion Mapping: Capable of detecting a range of specific emotions (such as joy, anger, sadness, and fear) rather than simple positive/negative sentiment.

Scalable Architecture: Built as a modular lab project, allowing for the addition of further AI features or expanded library integrations.
